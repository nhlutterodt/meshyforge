# Remesh API

Source: https://docs.meshy.ai/en/api/remesh

The Remesh API allows you to remesh and export existing 3D models generated by other Meshy APIs (like Image to 3D or Text to 3D) into various formats.

> **Note:** For format conversion and resizing, use the dedicated [Convert API](./14-convert.md) and [Resize API](./15-resize.md). The deprecated parameters below will continue to work, but we recommend the new endpoints for new integrations.

## Endpoints

| Method | Endpoint | Description |
|---|---|---|
| POST | `/openapi/v1/remesh` | Create a remesh task |
| GET | `/openapi/v1/remesh/:id` | Retrieve a remesh task |
| DELETE | `/openapi/v1/remesh/:id` | Delete a remesh task |
| GET | `/openapi/v1/remesh` | List remesh tasks (paginated) |
| GET | `/openapi/v1/remesh/:id/stream` | Stream a remesh task via SSE |

## Create a Remesh Task

Only one of `input_task_id` or `model_url` is required. If both are provided, `input_task_id` takes priority.

### Parameters

- **`input_task_id`** (string, Required): ID of a completed Text to 3D Preview, Text to 3D Refine, Image to 3D, or Retexture task. Must be `SUCCEEDED`.
- **`model_url`** (string, Required): 3D model via publicly accessible URL or Data URI. Supported formats: `.glb`, `.gltf`, `.obj`, `.fbx`, `.stl`. For Data URIs, use MIME type: `application/octet-stream`.
- **`target_formats`** (string[], default `["glb"]`): Output formats. Values: `glb`, `fbx`, `obj`, `usdz`, `blend`, `stl`, `3mf`.
- **`topology`** (string, default `"triangle"`): `quad` or `triangle`.
- **`target_polycount`** (integer, default `30,000`): Range 100 to 300,000.
- **`decimation_mode`** (integer): `1` (ultra), `2` (high), `3` (medium), `4` (low). When set, `target_polycount` is ignored.
- **`resize_height`** (number, ⚠ deprecated, default `0`): Resize to height in meters. Use [Resize API](./15-resize.md) instead. Mutually exclusive with `auto_size` and `resize_longest_side`.
- **`resize_longest_side`** (number, ⚠ deprecated, default `0`): Resize so longest bounding-box dimension equals value in meters. Use [Resize API](./15-resize.md) instead.
- **`auto_size`** (boolean, ⚠ deprecated, default `false`): AI vision estimates real-world height. Use [Resize API](./15-resize.md) instead.
  - **`origin_at`** (string, ⚠ deprecated, default `"bottom"`): `bottom` or `center`. Use [Resize API](./15-resize.md) instead.
- **`convert_format_only`** (boolean, ⚠ deprecated): If `true`, only change format, ignoring other inputs. Use [Convert API](./14-convert.md) instead. `target_formats` must be provided.
- **`alpha_thumbnail`** (boolean, default `false`): Render transparent-background preview.

### Request

```bash
# Basic remesh with custom formats and resize
curl https://api.meshy.ai/openapi/v1/remesh \
  -X POST \
  -H "Authorization: Bearer ${YOUR_API_KEY}" \
  -H 'Content-Type: application/json' \
  -d '{
    "input_task_id": "018a210d-8ba4-705c-b111-1f1776f7f578",
    "target_formats": ["glb", "fbx"],
    "topology": "quad",
    "target_polycount": 50000,
    "resize_height": 1.0,
    "origin_at": "bottom"
  }'

# Quad remesh with auto-size
curl https://api.meshy.ai/openapi/v1/remesh \
  -X POST \
  -H "Authorization: Bearer ${YOUR_API_KEY}" \
  -H 'Content-Type: application/json' \
  -d '{
    "input_task_id": "018a210d-8ba4-705c-b111-1f1776f7f578",
    "target_formats": ["glb", "fbx"],
    "topology": "quad",
    "target_polycount": 50000,
    "auto_size": true
  }'
```

### Response

```json
{
  "result": "0193bfc5-ee4f-73f8-8525-44b398884ce9"
}
```

### Failure Modes

- `400 - Bad Request`: Missing `model_url`/`input_task_id`, invalid input task, invalid model format, unreachable URL, invalid topology, mutually exclusive parameters.
- `401 - Unauthorized`: Authentication failed.
- `402 - Payment Required`: Insufficient credits.
- `429 - Too Many Requests`: Rate limit exceeded.

## Retrieve a Remesh Task

```bash
curl https://api.meshy.ai/openapi/v1/remesh/a43b5c6d-7e8f-901a-234b-567c890d1e2f \
  -H "Authorization: Bearer ${YOUR_API_KEY}"
```

## Delete a Remesh Task

```bash
curl --request DELETE \
  --url https://api.meshy.ai/openapi/v1/remesh/a43b5c6d-7e8f-901a-234b-567c890d1e2f \
  -H "Authorization: Bearer ${YOUR_API_KEY}"
```

Returns `200 OK` on success.

## List Remesh Tasks

### Parameters

- **`page_num`** (integer, default `1`): Page number.
- **`page_size`** (integer, default `10`): Max `50`.
- **`sort_by`** (string): `+created_at` or `-created_at`.

```bash
curl https://api.meshy.ai/openapi/v1/remesh?page_size=10 \
  -H "Authorization: Bearer ${YOUR_API_KEY}"
```

## Stream a Remesh Task (SSE)

```bash
curl -N https://api.meshy.ai/openapi/v1/remesh/a43b5c6d-7e8f-901a-234b-567c890d1e2f/stream \
  -H "Authorization: Bearer ${YOUR_API_KEY}"
```

## The Remesh Task Object

| Property | Type | Description |
|---|---|---|
| `id` | string | Unique identifier |
| `type` | string | `remesh` |
| `model_urls` | object | `glb`, `fbx`, `obj`, `usdz`, `blend`, `stl`, `3mf` |
| `thumbnail_url` | string | Preview image URL |
| `alpha_thumbnail_url` | string | Transparent-background preview (if `alpha_thumbnail: true`) |
| `progress` | integer | 0–100 |
| `status` | string | `PENDING`, `IN_PROGRESS`, `SUCCEEDED`, `FAILED` |
| `preceding_tasks` | integer | Count of preceding tasks (meaningful when `PENDING`) |
| `created_at` | timestamp | ms since epoch |
| `started_at` | timestamp | ms since epoch; 0 if not started |
| `finished_at` | timestamp | ms since epoch; 0 if not finished |
| `task_error` | object | Error details |
| `consumed_credits` | integer | Credits consumed (0 for `FAILED`) |
