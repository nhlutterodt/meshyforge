# Contributing to MeshyForge

Thank you for your interest in contributing to MeshyForge!

Please read the full [Contributing Guide](docs/CONTRIBUTING.md) for development setup, code conventions, testing, and the PR process.

## Quick Start

```bash
git clone https://github.com/nhlutterodt/meshyforge.git
cd meshyforge
npm install
npm run tauri dev
```

On first launch, enter your Meshy API key in **Settings**. It is stored in the OS keychain — no `.env` file needed.
